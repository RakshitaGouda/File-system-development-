# File System Development

This project demonstrates a basic file system simulation using Python.
It supports file creation, reading, writing, and deletion with inode-based file management.

## Platform
- Ubuntu Linux (VMware)

## Features
- Create, read, write, and delete files
- Inode table and block allocation
- GUI and TUI support
